## 手动更新 Google Scholar 引用数

编辑 `_data/citations.yml`：核对 `citedby`（总引用数）和各论文的 `num_citations`，再填写 `updated` 日期并提交到 main。GitHub Pages 构建后显示新数字，不再请求 Google Scholar 或引用数据分支。`title` 用来识别论文，键为 Scholar 论文 ID。初始数据保留历史缓存的日期，未重新核实。

在线编辑：https://github.com/ZhitianHou/zhitianhou.github.io/edit/main/_data/citations.yml
